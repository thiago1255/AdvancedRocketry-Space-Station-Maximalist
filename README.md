# AdvancedRocketry: Space Station Maximalist

**Fork of original https://github.com/Advanced-Rocketry/AdvancedRocketry**

Intended to make some features (already suggested including):

- [] Remove sattelites
- [] Add blocks on space stations to replace sattelites
- [] Antennas to exchange data
- [] Option to make EU the only energy accepted (for modpacks with energy type lore)
- [] Option to make force field projector require energy to operate
- [] Add propulsors required to rotate/move space station
- [] Add fuel engines required to travel with space station alongside with warp thing
- [] Add a multiblock computer
- More stuff involving space stations (accepting suggestions)
